# CROC Mobile Coloring — website

Live: https://ace9x.github.io/croc-mobile-coloring/

Static one-page site (HTML/CSS/JS, self-hosted Google Fonts under OFL — see `fonts/`). No build step.

## Filling in client details
Open `index.html` and edit `window.CROC_CONFIG` at the top. Empty values stay hidden on the page:
- `serviceArea`, `email`, `hours`
- `photos` — real job photos (turns on the "Recent work" section)
- `mascot` — crocodile mascot cut-out (shows in the hero)

Hero/background art is original generated imagery (styling only, not photos of past jobs).
